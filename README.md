# Frais

### A new way to interact with your mobile computer.

Frais is not designed to be another Android utility, launcher, or settings replacement.

**Frais is a system.**

The idea behind Frais is simple:

> **Pages contain widgets. Widgets have a purpose. Together, they become the interface to your mobile computer.**

Instead of forcing the user to navigate through endless settings, menus, and separate applications, Frais brings control, information, and actions into one organized environment.

---

## The Frais System

Frais is built around **Pages** and **Widgets**.

A **Page** represents a context or purpose.

A **Widget** represents a function.

This creates an interface where every part of the system has a reason to exist.

For example:

* The main Applications page gives quick access to the applications you use most.
* The Games page treats games separately because they have different requirements and behavior.
* The Secured Area contains things that should not have normal access.
* Other pages can contain widgets for reminders, information, system controls, productivity, or any other function.

The goal is not to create one enormous interface.

The goal is to create a system where **every page is composed of useful, focused pieces.**

---

# Complete Control Over Applications

At the heart of Frais is **application control**.

Your installed applications are not simply a list of icons.

Frais treats them as resources that the user should have control over.

Users can:

* Freeze and unfreeze applications.
* Control when applications are allowed to run.
* Define application launch conditions.
* Control application behavior.
* Organize applications into meaningful categories.
* Create filtered collections for faster access.
* Separate special categories such as games.
* Hide applications when necessary.
* Decide how and when applications should become available.

Every application belongs to a particular context or section, making the entire application environment easier to understand and control.

The objective is **super control without unnecessary complexity**.

---

# Applications Are Not All the Same

Frais does not treat every application equally.

A game is different from a messaging application.

A banking application is different from a media application.

A system application is different from something you only use once a month.

Frais therefore organizes applications according to their purpose and behavior.

The main application collection is filtered for fast everyday access.

Games have their own dedicated environment because they can have different launch, performance, and lifecycle requirements.

Other categories can evolve as the system grows.

The idea is to make the phone understand that **applications have different roles**, rather than treating them all as identical icons in a grid.

---

# The Secured Area

Frais also contains a **Secured Area**.

The Secured Area is designed for things that should not have ordinary access.

Applications, information, widgets, and other content can exist inside this environment without being part of the normal everyday interface.

The Secured Area is intended to become more than simply a hidden folder.

It is a different level of access within the Frais system.

This allows Frais to create controlled environments where the user decides:

**what is visible, what is accessible, and under which conditions it becomes available.**

---

# Widgets Are the Building Blocks

Widgets are one of the most important concepts in Frais.

A widget is not merely something that displays information.

**A widget has a purpose.**

It can provide:

* Information
* A shortcut
* A control
* A reminder
* An application interface
* A system function
* A contextual action
* A visual status
* An interaction with another application

Widgets can also have their own behavior, animations, states, and conditions.

This allows Frais to create experiences that are much more integrated than simply placing standard Android widgets on a screen.

For example, a widget could represent an application that is currently active, a secured application, a reminder, or a system function.

---

# Existing Android Widgets, Reimagined

Frais can also use existing Android widgets when they make sense.

For example, a productivity application such as Duolingo can provide a widget that shows:

* Your current streak
* Your progress
* A reminder to practice
* Motivation to continue

Instead of hiding that widget somewhere on the traditional Android home screen, Frais can incorporate it into a page where it has a clear purpose.

The same idea can apply to reminder applications, calendars, notes, productivity tools, and many other applications.

Frais therefore does not need to reinvent every useful feature.

It can **bring useful capabilities into the system and organize them around context and purpose.**

---

# One System Instead of Many Settings

The long-term vision of Frais is much larger than application management.

Android contains an enormous amount of functionality spread across:

* System Settings
* Separate utilities
* Permission screens
* Application-specific tools
* Launchers
* Widgets
* Device-management interfaces
* Developer tools
* System services

Frais aims to progressively bring these capabilities into one coherent system.

Through Android APIs, Shizuku, and deeper system integrations, Frais can eventually provide the user with direct control over many parts of the device without requiring them to constantly leave Frais and search through Android's settings.

The goal is not to duplicate Android for the sake of duplication.

The goal is to create a **better control layer over the mobile computer**.

---

# Shizuku as a Bridge to the System

Shizuku is an important part of this vision.

It allows Frais to access capabilities that ordinary applications cannot easily use while still operating within Android's security model.

This opens the door to deeper system integration and gives Frais the ability to progressively take responsibility for functions that would traditionally require separate tools or manual interaction with Android settings.

As Frais evolves, Shizuku can become one of the bridges between the Frais interface and the underlying Android system.

---

# The Future of Frais

The ultimate goal is for Frais to become a **unified operating layer for Android**.

Not a replacement operating system.

Not simply a launcher.

Not another settings application.

Instead, Frais should become the place where the user **interacts with and controls their mobile computer**.

You should not have to think:

> "Which Android setting controls this?"

or:

> "Which application do I need for this?"

The idea is that Frais should eventually provide the answer.

---

# A New Mobile Computer

Modern smartphones are incredibly powerful computers, yet much of their power is hidden behind fragmented interfaces.

Frais explores a different model.

Instead of organizing the device around applications and settings, organize it around **purpose**.

Instead of pages filled with icons, use **pages filled with functions**.

Instead of treating applications as passive software, give the user **control over their lifecycle and behavior**.

Instead of scattering system capabilities across Android, bring them into a unified interface.

Instead of asking the user to adapt to the system, make the system adapt to how the user wants to use it.

### Pages are contexts.

### Widgets are functions.

### Applications are controllable resources.

### The Secured Area defines controlled access.

### Shizuku connects Frais to deeper Android capabilities.

And together, these ideas form **Frais**.

> **Frais is an experiment in what a mobile computer could feel like if the user truly controlled the system.**
